SPEC §2.6. Reverse engineering is allowed for interop and is written up
under `docs/spec/` before code. No Valve code is copied. Some sources may
only be used for facts, not code: Proton (vtables, struct layouts),
Steamless (CC BY-NC-ND), community tables. See
[research-sources](../research-sources.md).
